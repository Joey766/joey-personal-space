# Joey Luo Personal Space

A bilingual cinematic personal website for Joey Luo.

## Structure

- Personal Space
- Projects and notes
- Life and interests
- Career Archive
- Chinese / English routes

## Local development

```bash
pnpm install
pnpm run dev
```
